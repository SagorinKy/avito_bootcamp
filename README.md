# Bot Detection — финальное решение

## Файлы

final_notebook.ipynb — финальный Jupyter Notebook с решением.

submission_0.csv — основной итоговый файл для отправки.

## Описание

В ноутбуке реализовано решение задачи классификации cookies на обычный и бот-трафик.

В решении используются:

временная валидация по нескольким временным фолдам;

официальная метрика Precision при Recall не менее 70% (P@R0.7);

базовый набор признаков и расширенный набор поведенческих признаков;

несколько моделей, включая Random Forest, HistGradientBoosting, LightGBM и CatBoost;

probability blending и rank blending для ансамблей.

В ноутбуке также оставлен отдельный старый вариант решения на 52 признаках и вариант с пятью дополнительными gap_* признаками. Эти модели используются для сравнения с более новым расширенным набором признаков.

## Финальная часть

Финальные кандидаты обучаются на полном train, после чего для test формируется score для каждого cookie_id.

Основной submission сохраняется в файл:

**submission_0.csv**

Файл содержит две колонки:

cookie_id — идентификатор cookie;

score — предсказанный score от 0 до 1.

Перед сохранением в ноутбуке выполняются проверки количества строк, уникальности cookie_id, отсутствия пропусков и попадания score в диапазон [0, 1].

Дополнительно ноутбук может сохранить:

submission_best_mean_0.csv;

submission_best_last_0.csv;

несколько дополнительных submission_candidate_*.csv.
